# 1. SUPER ADMIN UI DESIGN SPECIFICATION

## Design Theme & Visual System
- **Background**: Deep Navy & Obsidian Black (`#070B17`, `#080E21`, `#0B1222`, `#111A2C`)
- **Primary Accents**: Horology Sovereign Gold (`#D6A33A`, `#F6C453`)
- **Status Accents**: Emerald Green (`#16C784`), Cobalt Blue (`#2563EB`), Violet Purple (`#7C3AED`), Crimson Red (`#F05A67`)
- **Typography**: Inter Sans & Editorial Serif typography for luxury Horology branding
- **Elevation**: Multi-layered card surfaces with 1px border glows and backdrop-filter blur effects

## Layout Architecture
1. **Header**:
   - Shield with Golden Watch Crest (`WATCHHUB ATELIER / SUPER ADMIN COMMAND`)
   - Global search input with `Ctrl + K` hotkey trigger
   - `DB Online` real-time status pill
   - Notification bell with unread badge counter (`3`)
   - Profile avatar with 👑 crown badge (`Vikram Malhotra / Super Admin`)
2. **Sidebar**:
   - Navigation Sections: `SYSTEM ADMINISTRATION`, `BUSINESS CONTROL`, `OPERATIONS`
   - Active pill highlighted in solid gold (`#D6A33A`) with dark text
   - Bottom Atelier Enterprise Control Center luxury emblem
   - Prominent `Log Out Administrator` button with red accenting
3. **Users & Role-Based Permissions (Main View)**:
   - Breadcrumb navigation: `Home / System Administration / Users & Roles`
   - Header with `+ Add Staff Member` golden button
   - 4 KPI summary cards (Total Users, Active Users, Roles, Departments)
   - Search bar + Multi-select dropdown filters (Role, Department, Status, Reset)
   - Enterprise data table with action triggers (View, Edit, Permissions, Deactivate)
